# Cesar Smart для Home Assistant

Неофициальная интеграция для автомобильных сигнализаций **Cesar Smart / «Цезарь Сателлит»**.
Работает через тот же внутренний API, что и мобильное приложение Cesar Smart.

> **Неофициальный проект.** Не связан с АО «Цезарь Сателлит». Использует закрытый API
> мобильного приложения; API может измениться в любой момент, а использование может нарушать
> условия обслуживания. Всё — на ваш риск.

## Возможности

| Домен | Сущности |
|---|---|
| `switch` | Двигатель (автозапуск/глушение), Охрана (постановка/снятие) |
| `lock` | Центральный замок (открыть/закрыть) |
| `cover` | Багажник (только открытие — API не умеет закрывать) |
| `binary_sensor` | Двигатель работает, Зажигание, Охрана, Замки заперты, 4 двери, Багажник, Автозапуск с телефона |
| `sensor` | Топливо, Пробег, Температура двигателя/салона/улицы, Напряжение АКБ, Скорость, Баланс счёта, Баланс SIM, Время определения координат |
| `device_tracker` | Координаты автомобиля |
| `image` | Картинка автомобиля |
| `button` | Сигнал, Свет, Найти авто, Отменить поиск, Сервисный режим, Обновить координаты, Обновить данные |

## Требования

- Home Assistant **2026.1** или новее (используется `entry.runtime_data`).
- Аккаунт Cesar Smart (телефон + пароль от мобильного приложения).
- Автомобиль с установленной сигнализацией Cesar и активной подпиской.

## Установка

### HACS (кастомный репозиторий)

1. HACS → Интеграции → меню (⋮) → **Пользовательские репозитории**.
2. URL репозитория, категория **Integration**.
3. Установить **Cesar Smart**, перезапустить Home Assistant.
4. Настройки → Устройства и службы → **Добавить интеграцию** → **Cesar Smart**.

### Вручную

1. Скопируйте папку `custom_components/cesar_smart` в `/config/custom_components/`.
2. Перезапустите Home Assistant.
3. Добавьте интеграцию через интерфейс.

## Настройка

При добавлении интеграции доступны два способа:

- **По телефону и паролю** — введите номер (можно `+7…`, `8…` или просто цифры) и пароль
  приложения Cesar Smart. Интеграция сама получит refresh-токен.
- **Refresh-токен** — если вход по паролю не проходит (капча, 2FA, смена пароля).
  `device_id` указывать не обязательно.

Интеграция опрашивает облако каждые **120 секунд**; после команд состояние обновляется
через 8–18 секунд (зависит от команды).

## Ключи приложения (client_id / client_secret)

Интеграция **не содержит** ключей приложения Cesar — они принадлежат официальному
клиенту и могут быть отозваны. При добавлении интеграции появится шаг «Ключи приложения».

Взять их можно из APK Cesar Smart:

```bash
python tools/extract_keys.py "Cesar Smart.apk"
```

Скрипт находит `client_id` в `classes*.dex`, подбирает `client_secret` и проверяет пару
на сервере авторизации Cesar (валидная пара даёт `invalid_grant`, неверная — `401`).

Альтернатива: скопировать `custom_components/cesar_smart/const_local.example.py` в
`const_local.py`, заполнить ключи — тогда шаг ввода не появится (файл в `.gitignore`).

## Сущности и команды

| Сущность | Команды API |
|---|---|
| `switch.*_dvigatel` | `REMOTEON`, `REMOTEOFF` |
| `switch.*_okhrana` | `GUARD_ON`, `GUARD_OFF` |
| `lock.*_tsentralnyi_zamok` | `LOCK_OFF` (открыть), `LOCK_ON` (закрыть) |
| `cover.*_bagazhnik` | `BOOT_OPEN` — только открытие |
| `button.*_signal` | `HORN_ON` |
| `button.*_svet` | `LIGHT_ON` |
| `button.*_naiti_avto` | `FINDME_ON` |
| `button.*_otmenit_poisk` | `FINDME_OFF` |
| `button.*_servisnyi_rezhim_*` | `VALETON`, `VALETOFF` |

Состояние замка берётся из статуса `CAR_LOCK` (`CLOSED` → закрыт), двигателя — из
`ENGINE_STATE` (`RUNNING`), охраны — из `MODE` (`GUARD_MODE_ON`), багажника — из `DOOR_BOOT`.

## Яндекс Алиса (Yandex Smart Home)

Интеграция хорошо дружит с [Yandex Smart Home](https://github.com/dext0r/yandex_smart_home)
(облако yaha-cloud). Пример конфигурации — в [`examples/configuration.yaml`](examples/configuration.yaml).

Важные ограничения УДЯ:

- Одно устройство в Алисе = одна сущность HA. Двигатель, замок и багажник будут **тремя
  отдельными устройствами** — объединить их нельзя (YSH формирует устройство по `entity_id`).
- Тип `devices.types.openable.door_lock` УДЯ не принимает; для замка используйте
  `devices.types.openable` + capability `on_off`.
- «Закрыть багажник» вернёт ошибку: в API нет `BOOT_CLOSE`.

Подробнее — [`docs/YANDEX_SMART_HOME.md`](docs/YANDEX_SMART_HOME.md).

## Ограничения

- Только облако Cesar (локального канала нет), нужен интернет.
- Закрытие багажника не поддерживается API.
- Двери/капот отдаются только как статусы, отдельных команд нет.
- Часть датчиков может быть `unknown`, если сигнализация их не передаёт
  (например, температура двигателя или баланс SIM).
- Учётные данные хранятся в `.storage` Home Assistant (refresh-токен), пароль — нет.
